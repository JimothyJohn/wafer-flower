Make your own — the sculpture as a program

This piece isn't drawn, it's generated — which means it can be regenerated as something else. Drag any slider and the whole halo re-derives live: more wafers, a deeper swirl, a wider ring, and every consequence (geometry, bond stresses, weight, margins) follows automatically. This is a coarse preview for exploring the design space; when it looks right, Download STL grabs the preview solid at those exact values and the command line regenerates the full CI-checked printable CAD. The CAD viewer shows the finished parts, and the engineering page has every derivation if you want to know why the silicon allows what it allows.
